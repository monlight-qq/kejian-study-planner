# 课间 · 手机学习计划

一个可添加到手机主屏幕的 PWA，中文界面，核心页面使用原生 HTML / CSS / JavaScript，OCR 引擎与模型内置。

源码仓库：`kejian-study-planner`。Android APK 和 SHA-256 校验文件放在仓库的 Releases 页面；下载最新版安装即可，使用相同签名覆盖更新会保留原有数据。

## 启动

在 `mobile` 目录运行：

```powershell
node server.cjs
```

电脑访问 http://localhost:4173 。手机和电脑连接同一个 Wi-Fi 后，访问 `http://电脑局域网IP:4173`（可用 `ipconfig` 查看 IPv4 地址；需要系统防火墙允许此端口）。也可以将本目录完整部署到任意支持 HTTPS 的静态服务器。

## 在手机上安装

PWA 安装、Service Worker 和离线缓存需要 **HTTPS**；电脑 `localhost` 是开发例外。手机访问电脑的普通 HTTP 局域网地址可使用页面和保存数据，但不具备完整安装及离线功能。

- Android：在 HTTPS 页面使用支持 PWA 的浏览器，菜单 → 安装应用 / 添加到主屏幕；支持安装提示时，设置页也会出现安装按钮。
- iPhone：用 Safari 打开 HTTPS 页面，分享 → 添加到主屏幕。
- 首次联网打开并成功完成缓存后，可从主屏幕离线打开。

浏览器版本是 PWA。同时提供 Android APK：`dist/kejian-1.7.2.apk`，可直接在 Android 8.0 及以上系统安装。安装包内置全部页面，首次启动也不需要网络或电脑服务器。当前未提供 iOS 原生安装包。

## 功能

- 今日概览：首页优先显示当天全部课程，包含开始 / 结束时间、地点；突出正在上课与下一节课，并按学期单双周筛选。下方保留待完成作业、未来七天考试与累计完成数。
- 作业：自由输入科目、内容、开始日期、截止日期和时间、优先级与备注；新增、编辑、完成、恢复、删除、搜索及筛选。科目不再显示下拉建议。
- 活动：首页“活动安排”添加活动名称、日期、时间和备注；支持编辑、删除、标记结束、恢复及待参加 / 已结束 / 全部筛选。活动只显示在日历的实际当天，可以选择提前 6 小时和提前 3 小时的 Android 通知，记录与提醒设置随 JSON 备份保存。
- 复习与考试：科目、复习开始日期、考试名称、考试时间与备注；按行添加复习项目，逐项勾选并自动计算进度；支持标记考试结束。
- 日期选择：开始日期和截止 / 考试日期使用同一套月历弹窗，支持年月切换、今天、键盘方向键与取消；时间单独设置。选择新日期导致范围倒置时，另一端自动跟随调整。
- 课程表：记录课程、星期、开始 / 结束时间、地点与备注，支持每周、单周、双周；按周查看或查看全部课程，编辑、删除及同周次时间重叠提示。
- 上课周数：创建和编辑时选择第 1–20 周，支持全选、清空、连续范围和逐周勾选；所选周次与单双周同时生效。选择第 1–12 周即可提前结课，取消某周可跳过整周。
- 调休与临时调整：在课程创建 / 编辑界面添加指定日期停课、调到另一天或临时加课；调课可修改时间和地点。保存课程后生效，取消编辑会保留原安排；首页和日历都按调整后的实际日期显示。所有课程列表按开始时间从早到晚排序。
- 批量调休：课程页 → 批量调休，选择调休前原上课日与调休后新上课日，自动预览当天全部实际课程并一键导入；沿用每门课的时间、地点，按单双周及周数筛选。默认整体移课，可选择复制补课；目标日原课程默认保留，也可勾选当天停课。会提示时段重叠、避免重复复制，已有单门调课和临时加课也能继续整体调整。
- 学期周次：课程页点击“第几周”或学期起点，设置第 1 周的周一；任意日期会自动对齐该周周一。单双周按学期计算，跨年连续；学期开始前不显示课程。
- 日历：显示开始至截止 / 考试之间的每一天，包括跨月和跨年的中间日期；点击查看进行中计划、截止任务以及按单双周筛选的课程。未填写开始日期的旧记录仅显示截止日。
- 界面：五项底部导航、亮暗主题、页面切换和分段选项动效、弹窗动效；遵循系统减少动态效果设置。
- 动效：亮暗切换保留参考 [qihua123.top](https://qihua123.top) 的按钮中心圆形过渡，导航滑块、分段滑块、弹窗进出与按压反馈保持统一。页面切换在更新内容和恢复滚动位置前捕获旧页面，再用 280 毫秒连续淡入淡出衔接新页面；快照保持各自原始尺寸和位置，并使用互补透明度混合避免中间变暗。底部导航使用最高页面层级；页面快照按顶部栏和导航的实际位置裁切，切换中二者保持可见且可操作，兼容屏幕安全区和桌面外边距。快速切换以最新页面为准，打开弹窗、调整窗口或减少动态效果时结束当前过渡并提交待更新的页面。旧 WebView 直接更新页面，主题使用颜色渐变与图标旋转。弹窗在退出动画结束后原生关闭并恢复焦点；减少动态效果时关闭动画。
- 备份：JSON 导出与导入，包含计划、课程和学期周次；导入经完整校验并确认后合并，同编号更新，兼容旧版备份。清空和删除均须确认。
- 设置中可主动添加 4 条带 `【示例】` 标记的体验记录，首次打开默认没有用户记录。
- 主题：首页右上角快速切换亮暗；设置 → 外观主题，可选亮色、暗色或跟随系统。选择保存在本机，主题也覆盖表单、详情、日历和弹窗。
- 提醒：作业、考试和活动可选择提前 6 小时、提前 3 小时各一次的 Android 本地通知，两次分别去重。完成、删除或关闭提醒后取消；修改日期时间后按新时间重新安排。示例记录默认不发送通知。

## Android APK

### 从截图导入课程表

1. 打开“课程” → “从截图导入课表” → “选择截图”，选择完整、正向、文字清晰的 PNG、JPG 或 WebP 课表图片。
2. 点击“开始识别”。Android 使用系统图片选择器，无需存储权限；OCR 引擎与中英文模型内置，截图不上传，APK 首次启动即可离线识别。浏览器版首次联网完成离线缓存后也可断网识别。

识别保留中文行边界，分别提取课程名、地点和时间。课程名与地点在同一行也会按字段分开；支持中文楼名、字母教室号，以及“宏智楼2 / 15”“信智楼B / 411室”等窄列换行。含“大节”分组的表格按星期列和节次定位，再逐格识别，避免把相邻课程合并；左侧跨行的时间与小节编号会按对应的大节填入。低置信度格子会进行带留白的清晰度复识别，仍不确定的文字标为“重点核对”。省略号截断的课程名保留省略号，并在备注中提醒补充完整名称。
3. 对照原图校对课程名、星期、时间、地点及单双周。可以移除误识别项、取消勾选不导入的课程，或补充遗漏课程；缺少的必填信息须补齐。
4. 如果截图只有“第几节”，展开学校作息，填写对应节次的真实时间，再应用到空白时间。无法确认的节次或时间需要手动填写，不按通用作息猜测。
5. 展开“上课周数”检查第 1–20 周的识别结果，可以逐周选择或按范围修改。点击“确认导入”后与现有课表合并，相同名称、星期、单双周、有效周次、时间、地点的课程跳过；保留原有作业和复习计划。单双周仍按学期第 1 周设置计算。

支持常见按星期分列的课表与含星期、时间的文字列表。图片清晰度、排版、复杂合并单元格等会影响识别结果，保存前请逐项核对。第 1–20 周内的周次区间和不连续周次可识别为可修改的上课周数；未能识别时默认选择 1–20 周，原图周次文字保留在备注。超出 20 周的原图周次须手动核对。

停课和调课的原日期必须符合该课程所选周次、星期及单双周；同一个原上课日期只允许一项停课或调课。调课会取消原日期的一次课程，并在目标日期显示调整后的时间和地点；加课不受原星期、单双周限制。所有安排均在学期第 1–20 周内，地点留空时沿用课程地点。更改学期起点或课程周次后，原日期不再符合规则的调课不会继续显示；请同步检查临时调整。旧版课程自动补充为第 1–20 周，调休记录与周次都包含在备份中。

OCR 使用 [Tesseract.js 的本地资源配置](https://github.com/naptha/tesseract.js/blob/v6.0.1/docs/local-installation.md) 与中英文模型，开源许可证及资源来源保存在 `assets/ocr/`。新增图片导入使用 Android 系统文档选择器，在后台解码并缩放至适合识别的尺寸。

把 `dist/kejian-1.7.2.apk` 传到手机，点击文件，按系统提示允许该文件管理器安装应用，再安装即可。与旧版包名及签名相同，可直接覆盖安装，保留原有记录与主题。浏览器版本与 Android 应用分别保存数据，可以通过设置中的 JSON 备份迁移。旧记录未填写的开始日期可在编辑时补充。

应用包名 `com.kejian.planner`，版本 1.7.2，最低 Android 8.0（API 26），目标 Android 15（API 35）。使用原生 WebView 加载内置 HTTPS 资源，未申请联网或存储权限；备份导出和导入使用 Android 系统文件选择器。为发送提醒，声明通知、准时闹钟和开机恢复权限。请保持系统 Android WebView 处于较新的版本。卸载或清除应用数据会删除本机记录，请先导出备份。

### 开启提前 6 小时和提前 3 小时提醒

1. 添加或编辑作业、考试或活动时，勾选“提前 6 小时和提前 3 小时提醒我”，设置截止 / 考试 / 活动时间；详情中可以查看两次提醒的具体日期时间。
2. Android 13 及以上系统首次添加有效提醒时，会申请通知权限。也可到应用设置 → 提前提醒 → 开启通知。
3. Android 12 及以上可点击“准时提醒设置”，在系统页面允许课间的“闹钟与提醒”。未允许时仍安排普通提醒，系统可能延后发送。
4. 点击“10 秒后测试提醒”，可在手机上验证通知。未开启准时提醒时，测试也可能被系统延后。

提醒在截止 / 考试 / 活动前 6 小时和 3 小时各发送一次。例如 11 月 20 日 18:00 截止，会在当天 12:00 和 15:00 提醒。提前时长按实际经过的小时计算，跨日与夏令时也保持 6 小时 / 3 小时。若添加或恢复时距时间不足 6 小时但大于 3 小时，会尽快补发当前的 6 小时阶段，再保留 3 小时阶段；已不足 3 小时只补发最近阶段的一条，已到时间不补发。相同记录和日期时间的两个阶段分别去重，改期重新安排，升级时保留原记录与提醒开关。通知点击后打开该计划详情。

原生提醒独立于 WebView 页面保存，应用关闭后仍由 Android AlarmManager 调度；系统重启、升级、时间或时区变化后重新安排。若强制停止应用，需再次打开以恢复提醒。通知被禁用或系统限制后台时可能无法按时收到，设置页会显示通知与准时提醒状态。浏览器 PWA 只保存提醒选择，不发送关闭页面后的系统通知。

实现遵循 [Android 通知运行时权限](https://developer.android.com/develop/ui/compose/notifications/notification-permission) 与 [Android 闹钟调度说明](https://developer.android.com/develop/background-work/services/alarms)。

### 重新打包

```powershell
npm run build:apk
# 自定义 SDK 与 JDK 路径：
powershell -ExecutionPolicy Bypass -File android/build.ps1 -SdkPath C:\Android\Sdk -JavaPath C:\Java\jdk-17
```

构建脚本使用 JDK 17、官方 Android SDK Platform 35 与 Build Tools 35，执行资源打包、Java 编译、DEX 转换、对齐和签名，不依赖 Android Studio 或 Gradle。当前工作区的 SDK 位于 `.android-sdk/`，JDK 默认路径是 `E:\jdk`。

签名密钥与随机生成的口令保存在 `android/keys/`，已加入 `.gitignore`，不会打包进 APK。**务必妥善保存整个 keys 目录**；后续更新需要相同签名才能覆盖安装并保留数据。APK 的 SHA-256 摘要位于 `dist/kejian-1.7.2.apk.sha256`。

构建工具与签名检查参考 [Android 官方命令行构建说明](https://developer.android.com/build/building-cmdline) 和 [apksigner 文档](https://developer.android.com/tools/apksigner)。

计划保存在当前浏览器 / Android 应用 WebView 的 localStorage，不跨设备同步。Android 提醒安排另保存在应用私有存储中。隐私模式、清除站点或应用数据、更换浏览器或访问地址可能导致记录不可用，请定期导出备份。
